# Road2English

A free, static Life in the UK test practice app. It uses original study questions organized around the broad subject areas in the official Guide for New Residents and runs entirely in the browser.

## Run it

Open `index.html` in a browser. No build step, server, account or dependencies are required. For local development, any static file server can serve this folder.

## What's included

- 100 original questions across five guide-aligned topics (20 per topic)
- Select-one and select-two questions, with matching answer checking and scoring
- Untimed practice with selectable question counts
- A 24-question, 45-minute mixed mock exam
- Topic selection, question navigation and answer checking
- Submission guard for unanswered questions and a clickable results review

This is an independent study aid, not an official test or a substitute for the official handbook. The questions are independently written and are not official test questions.

GOV.UK says the test covers information from the official Guide for New Residents. For authoritative preparation guidance and test details, see the [official GOV.UK Life in the UK Test page](https://www.gov.uk/life-in-the-uk-test) and the [official Life in the UK Test shop](https://www.officiallifeintheuk.co.uk/shop).
